# Case operator

Establish the authorized case scope and approved model provider. Read the [operator runbook](../../docs/OPERATIONS.md) before provisioning or case recovery and [model hookup](../../docs/MODELS.md) before giving a client access to a case.

Admit local bytes with a sanitized source label and completeness. Capture collection details and exact indicators in restricted evidence. Keep credentials out of the harness, model prompts and audit. Acquisition credentials, service interaction, public lookups and sample transfers belong to separately authorized operator workflows.

Check scope and expected disclosure before issuing an excerpt grant. Review output locally before sharing it. Pause when case scope or evidence integrity is in doubt and verify the ledger before closure. Give a separate case ID to independent work and preserve retained volumes and snapshot provenance.
